Q1 ✓ Correct Logic · products of integers
Official\(42\) Yunje\(42\)
Problem
Six consecutive positive integers are split among three people, two each. Ethan's two multiply to \(20\), Jacob's to \(24\). Compute the product of Karthik's two numbers.
Solution
  1. \(20=4\cdot5\): the only pair of integers (within 6 consecutive) with product \(20\).
  2. \(24=4\cdot6\) or \(3\cdot8\); since \(4\) is taken, Jacob holds \(3,8\).
  3. So the six integers are \(3,4,5,6,7,8\); Karthik gets the leftovers \(6,7\).
  4. \(\therefore 6\cdot7=42.\)
→ Official solution (P1)
Q2 ✓ Correct Geometry · regular hexagon
Official\(\tfrac34\) Yunje\(\tfrac34\)
Problem
Let \(RANDOM\) be a regular hexagon of side \(1\). Points \(I,T\) lie on \(RA,DO\) with \(MI=MT\) and \(\angle TMI=90^\circ\). Compute the area of \(\triangle MIT\).
Solution
  1. By symmetry \(IT\perp RA\) and \(IT\perp DO\), so \(IT\) equals the hexagon's height \(=\sqrt3\).
  2. \(\triangle MIT\) is right-isosceles at \(M\) with hypotenuse \(IT\).
  3. Area \(=\tfrac14\,IT^2=\tfrac14\cdot3=\tfrac34.\)
→ Official solution (P2)
Q3 ✓ Correct Number theory · exponents
Official\(13\) Yunje\(13\)
Problem
Distinct positive integers \(a,b,c\) satisfy \(a^b\,b^c=a^c\). Find the minimum possible value of \(a+b+c\).
Solution
  1. Divide: \(a^b b^c=a^c\Rightarrow b^c=a^{\,c-b}\), so \(a,b\) are powers of a common base, \(b<a\).
  2. Try powers of \(2\): \((a,b)=(8,2)\Rightarrow 2^c=8^{\,c-2}=2^{3c-6}\Rightarrow c=3\).
  3. \((a,b,c)=(8,2,3)\) are distinct, \(a+b+c=13\); no smaller works.
  4. \(\therefore 13.\)
→ Official solution (P3)
Q4 ✓ Correct Number theory · base-10 digits
Official\(26\) Yunje\(26\)
Problem
How many \(3\)-element subsets of \(\{10^1{+}1,10^2{+}1,\dots,10^7{+}1\}\) have a product whose base-10 digits are all \(0\) or \(1\)?
Solution
  1. \((10^a{+}1)(10^b{+}1)(10^c{+}1)\) expands into a sum of \(8\) powers of \(10\).
  2. All digits are \(0/1\) \(\iff\) the exponents \(a{+}b{+}c,b{+}c,a{+}c,a{+}b,a,b,c\) are all distinct.
  3. With \(a<b<c\) the only possible clash is \(a+b=c\); there are exactly \(9\) such triples.
  4. \(\therefore \binom73-9=35-9=26.\)
→ Official solution (P4)
Q5 ✓ Correct Recursion · base 3
Official\(156\) Yunje\(156\)
Problem
\(f(0)=0\) and \(f(3n{+}2)=f(3n{+}1)=f(3n){+}1=3f(n){+}1\) for \(n\ge0\). Compute the sum of all \(m\) with \(f(m)=13\).
Solution
  1. In base \(3\), \(f\) takes a numeral and replaces every digit \(2\) by \(1\).
  2. \(13=111_3\), so \(f(m)=13\iff m=\overline{abc}_3\) with each digit \(\in\{1,2\}\).
  3. Each position is \(1\) or \(2\), each \(4\) times: sum \(=(4{\cdot}1+4{\cdot}2)(9+3+1)=12\cdot13=156.\)
→ Official solution (P5)
Q6 ✓ Correct Number theory · digit casework
Official\(135\) Yunje\(135\)
Problem
\(n\) is stacked if \(2n\) has the same number of digits as \(n\) and each digit of \(2n\) is a multiple of the corresponding digit of \(n\). Count the stacked integers below \(1000\).
Solution
  1. 1-digit: \(1,2,3,4\) \(\Rightarrow 4\).
  2. 2-digit: \(4\cdot5=20\) with both digits \(<5\), plus \(15\) \(\Rightarrow 21\).
  3. 3-digit: \(100\) with all digits \(<5\), plus \(195;\ 115,215,315,415;\ 150\text{–}154\) \(\Rightarrow 110\).
  4. \(\therefore 4+21+110=135.\)
→ Official solution (P6)
Q7 ✓ Correct Geometry · tangent circle, similarity
Official\(\tfrac{40\sqrt3}{39}\) Yunje\(\tfrac{40\sqrt3}{39}\)
Problem
In \(\triangle ABC\), \(AB=5,\ BC=8,\ \angle ABC=60^\circ\). A circle \(\omega\) tangent to \(AB,BC\) meets \(CA\) at \(X,Y\) (order \(C,Y,X,A\)); \(\omega\) touches \(AB\) at \(Z\) with \(ZY\parallel BC\). Compute the radius of \(\omega\).
Solution
  1. Let \(\omega\) touch \(BC\) at \(T\). \(BZ=BT\) and \(\angle B=60^\circ\Rightarrow\triangle BZT\) is equilateral.
  2. Tangent at \(T\parallel BC\Rightarrow TY=TZ\); with the \(60^\circ\) angles \(\triangle TYZ\) is equilateral, side \(x\).
  3. \(\triangle AYZ\sim\triangle ABC:\ \tfrac{5-x}{5}=\tfrac{x}{8}\Rightarrow x=\tfrac{40}{13}\).
  4. Radius \(=\tfrac{x}{\sqrt3}=\tfrac{40}{13\sqrt3}=\tfrac{40\sqrt3}{39}.\)
  5. ✓ Yunje wrote exactly \(\tfrac{40\sqrt3}{39}\) — the rationalized official form.
→ Official solution (P7)
Q8 ✓ Correct Algebra · nested absolute value
Official\(285\) Yunje\(285\)
Problem
Let \(f(x)=\big|\cdots\big||x|-1\big|-2\big|-\cdots-10\big|\). Compute \(f(1)+f(2)+\cdots+f(55)\).
Solution
  1. \(f\) is piecewise linear with slopes \(\pm1\); cusps occur where \(|x|\) is a triangular number \(T_k\).
  2. \(f(0)=5\); on \([T_k,T_{k+1})\) the values average \(5\) (\(k\) even) or \(5.5\) (\(k\) odd).
  3. Sum \(=5(3{+}5{+}7{+}9)+5.5(2{+}4{+}6{+}8{+}10)=120+165=285.\)
→ Official solution (P8)
Q9 ◐ Partial Geometry · hexagon, two right angles
Official\(\tfrac12,\ \tfrac{\sqrt7}{7}\) Yunje\(\tfrac12,\ \tfrac{\sqrt7}{17}\)
Problem
Regular hexagon \(ABCDEF\), center \(O\), side \(1\). Interior point \(X\) satisfies \(\angle BXC=\angle AXE=90^\circ\). Compute all possible values of \(OX\).
Solution
  1. \(X\) lies on both the circle with diameter \(BC\) and that with diameter \(AE\): two intersection points.
  2. \(X_1=AC\cap BE\) gives \(OX_1=\tfrac12\). ✓ Yunje found this value.
  3. For \(X_2\): \(OX_2MN\) is an isosceles trapezoid; law of cosines gives \(MN=\tfrac{\sqrt7}{2}\), and Ptolemy gives \(OX_2\cdot MN=\tfrac12\).
  4. \(\therefore OX_2=\dfrac{\tfrac12}{\sqrt7/2}=\dfrac{1}{\sqrt7}=\dfrac{\sqrt7}{7}.\)
  5. Error: Yunje wrote \(\tfrac{\sqrt7}{17}\) — the denominator should be \(7\) (i.e. \(1/\sqrt7\)), not \(17\).
→ Official solution (P9)
Q10 ✗ Wrong Combinatorics · partitions, casework
Official\(203\) Yunje\(45\)
Problem
Let \(S=\{1,2,\dots,64\}\). Compute the number of partitions of \(S\) into \(16\) arithmetic sequences, each of length \(4\) with common difference \(1\), \(4\), or \(16\).
Solution
  1. Key claim: no partition can use all three differences \(1,4,16\) — a spacing argument forces it down to two.
  2. Case \(\{1,16\}\): #(diff-16) is a multiple of \(4\); the count is \(\binom{16}{0}+\binom{13}{1}+\binom{10}{2}+\binom73+\binom44=95\).
  3. Case \(\{4,16\}\): each residue class chooses diff-4 or diff-16 independently \(\Rightarrow 2^4=16\).
  4. Case \(\{1,4\}\): same composition count as \(\{1,16\}\) \(\Rightarrow 95\).
  5. Total \(95+16+95=206\), minus \(3\) single-difference partitions counted twice \(\Rightarrow 203\).
  6. Yunje wrote \(45\): the three-case structure was missed — see the deep dive below.
→ Official solution (P10)

Deep Dive — Problem 10: casework + counting compositions

  1. Structure: a partition cannot use all three differences \(1,4,16\) at once — it forces a contradiction. So only two-difference cases survive: \(\{1,16\},\{4,16\},\{1,4\}\). Breaking the problem into three pieces is the whole game.
  2. Counting compositions: in case \(\{1,16\}\), how you lay out \(1\!-\!16\) into diff-1 blocks (length 4) and diff-16 slots (groups of 4) determines the entire partition. That equals the number of ordered compositions of \(16\) into parts \(1\) and \(4\), which is \(95\).
  3. Other cases: \(\{4,16\}\) lets each residue class pick independently \(\Rightarrow 2^4=16\); \(\{1,4\}\) is again the composition count \(95\).
  4. Inclusion–exclusion: \(95+16+95=206\), minus the \(3\) single-difference partitions double-counted, gives \(\mathbf{203}\). Always check you haven't counted the same object twice.
Practice 1. Count the ordered compositions of \(16\) using parts \(1\) and \(4\). (e.g. \(4{+}4{+}4{+}4\), \(1{+}1{+}\cdots{+}1\), \(4{+}1{+}\cdots\))
Show solution
  1. With \(k\) parts equal to \(4\), there are \(16-4k\) ones, so \(16-3k\) parts total.
  2. Place the \(4\)s in \(\binom{16-3k}{k}\) ways: \(k=0,1,2,3,4\Rightarrow 1,13,45,35,1\).
  3. \(\therefore 1+13+45+35+1=\mathbf{95}\) — exactly the key count in Problem 10.
Practice 2. Count the ordered compositions of \(8\) using parts \(1\) and \(2\).
Show solution
  1. The last part is \(1\) or \(2\), so \(g(n)=g(n-1)+g(n-2)\).
  2. \(g(1),g(2),\dots=1,2,3,5,8,13,21,34\) (Fibonacci).
  3. \(\therefore g(8)=\mathbf{34}.\)

Q1 ✓ 정답 논리 · 정수의 곱
공식 정답\(42\) 유윤제\(42\)
문제
연속한 양의 정수 \(6\)개를 세 사람에게 \(2\)개씩 나눠 준다. Ethan 두 수의 곱은 \(20\), Jacob 두 수의 곱은 \(24\). Karthik 두 수의 곱을 구하라.
풀이
  1. \(20=4\cdot5\): 연속한 6수 안에서 곱이 \(20\)인 쌍은 \(4,5\) 뿐.
  2. \(24=4\cdot6\) 또는 \(3\cdot8\); \(4\)는 이미 쓰였으므로 Jacob은 \(3,8\).
  3. 여섯 수는 \(3,4,5,6,7,8\); 남은 \(6,7\)이 Karthik의 것.
  4. \(\therefore 6\cdot7=42.\)
→ 공식 해설 (문제 1)
Q2 ✓ 정답 기하 · 정육각형
공식 정답\(\tfrac34\) 유윤제\(\tfrac34\)
문제
정육각형 \(RANDOM\) (한 변 \(1\)). \(I\in RA,\ T\in DO\), \(MI=MT\), \(\angle TMI=90^\circ\). \(\triangle MIT\)의 넓이를 구하라.
풀이
  1. 대칭성으로 \(IT\perp RA,\ IT\perp DO\) → \(IT\)는 육각형의 높이 \(=\sqrt3\).
  2. \(\triangle MIT\)는 \(M\)에서 직각인 직각이등변삼각형, 빗변이 \(IT\).
  3. 넓이 \(=\tfrac14\,IT^2=\tfrac14\cdot3=\tfrac34.\)
→ 공식 해설 (문제 2)
Q3 ✓ 정답 정수론 · 지수
공식 정답\(13\) 유윤제\(13\)
문제
서로 다른 양의 정수 \(a,b,c\)가 \(a^b\,b^c=a^c\)를 만족. \(a+b+c\)의 최솟값을 구하라.
풀이
  1. 양변을 나누면 \(a^b b^c=a^c\Rightarrow b^c=a^{\,c-b}\) → \(a,b\)는 같은 밑의 거듭제곱, \(b<a\).
  2. \(2\)의 거듭제곱: \((a,b)=(8,2)\Rightarrow 2^c=8^{\,c-2}=2^{3c-6}\Rightarrow c=3\).
  3. \((8,2,3)\)은 서로 다르고 \(a+b+c=13\); 더 작은 값은 없음.
  4. \(\therefore 13.\)
→ 공식 해설 (문제 3)
Q4 ✓ 정답 정수론 · 자릿수
공식 정답\(26\) 유윤제\(26\)
문제
\(\{10^1{+}1,10^2{+}1,\dots,10^7{+}1\}\)의 \(3\)원소 부분집합 중, 세 수의 곱이 \(10\)진법에서 자릿수가 모두 \(0\) 또는 \(1\)인 것의 개수.
풀이
  1. \((10^a{+}1)(10^b{+}1)(10^c{+}1)\)를 전개하면 \(10\)의 거듭제곱 \(8\)개의 합.
  2. 모든 자리가 \(0/1\) \(\iff\) 지수 \(a{+}b{+}c,b{+}c,a{+}c,a{+}b,a,b,c\)가 모두 서로 다름.
  3. \(a<b<c\)에서 겹칠 수 있는 건 \(a+b=c\)뿐 → 그런 삼중쌍은 \(9\)개.
  4. \(\therefore \binom73-9=35-9=26.\)
→ 공식 해설 (문제 4)

\(2n\)이 \(n\)과 자릿수가 같고 \(2n\)의 각 자리가 \(n\)의 대응 자리의 배수이면 \(n\)을 stacked라 한다. \(1000\) 미만의 stacked 정수의 개수.

Q7 ✓ 정답 기하 · 접하는 원·닮음
공식 정답\(\tfrac{40\sqrt3}{39}\) 유윤제\(\tfrac{40\sqrt3}{39}\)
문제
\(\triangle ABC\)에서 \(AB=5,\ BC=8,\ \angle ABC=60^\circ\). \(AB,BC\)에 접하는 원 \(\omega\)가 \(CA\)와 \(X,Y\)에서 만남(순서 \(C,Y,X,A\)); \(\omega\)는 \(AB\)와 \(Z\)에서 접하고 \(ZY\parallel BC\). \(\omega\)의 반지름을 구하라.
풀이
  1. \(\omega\)가 \(BC\)에 접하는 점을 \(T\). \(BZ=BT\), \(\angle B=60^\circ\Rightarrow\triangle BZT\)는 정삼각형.
  2. \(T\)에서의 접선이 \(BC\)와 평행 → \(TY=TZ\); \(60^\circ\)각들로 \(\triangle TYZ\)도 정삼각형, 한 변 \(x\).
  3. \(\triangle AYZ\sim\triangle ABC:\ \tfrac{5-x}{5}=\tfrac{x}{8}\Rightarrow x=\tfrac{40}{13}\).
  4. 반지름 \(=\tfrac{x}{\sqrt3}=\tfrac{40}{13\sqrt3}=\tfrac{40\sqrt3}{39}.\)
  5. ✓ 유윤제는 정확히 \(\tfrac{40\sqrt3}{39}\) (유리화한 공식 정답 형태)로 적음.
→ 공식 해설 (문제 7)

Q9 ◐ 부분 정답 기하 · 육각형·두 직각
공식 정답\(\tfrac12,\ \tfrac{\sqrt7}{7}\) 유윤제\(\tfrac12,\ \tfrac{\sqrt7}{17}\)
문제
정육각형 \(ABCDEF\), 중심 \(O\), 한 변 \(1\). 내부 점 \(X\)가 \(\angle BXC=\angle AXE=90^\circ\). \(OX\)의 가능한 모든 값을 구하라.
풀이
  1. \(X\)는 지름이 \(BC\)인 원과 지름이 \(AE\)인 원 위에 동시에 있음 → 교점 두 개.
  2. \(X_1=AC\cap BE\) → \(OX_1=\tfrac12\). ✓ 유윤제가 맞힌 값.
  3. \(X_2\): \(OX_2MN\)은 등변사다리꼴; 코사인법칙으로 \(MN=\tfrac{\sqrt7}{2}\), 톨레미로 \(OX_2\cdot MN=\tfrac12\).
  4. \(\therefore OX_2=\dfrac{\tfrac12}{\sqrt7/2}=\dfrac{1}{\sqrt7}=\dfrac{\sqrt7}{7}.\)
  5. 오답: 유윤제는 \(\tfrac{\sqrt7}{17}\)로 적음 — 분모는 \(7\)(즉 \(1/\sqrt7\))이어야 하며 \(17\)이 아님.
→ 공식 해설 (문제 9)
Q10 ✗ 오답 조합 · 분할·경우의 수
공식 정답\(203\) 유윤제\(45\)
문제
\(S=\{1,2,\dots,64\}\). \(S\)를 길이 \(4\)이고 공차가 \(1,4,16\) 중 하나인 등차수열 \(16\)개로 분할하는 경우의 수를 구하라.
풀이
  1. 핵심 주장: 세 공차 \(1,4,16\)을 모두 쓰는 분할은 불가능 (간격 논증) → 항상 두 종류만 사용.
  2. 경우 \(\{1,16\}\): 공차 16 수열 개수는 \(4\)의 배수 → \(\binom{16}{0}+\binom{13}{1}+\binom{10}{2}+\binom73+\binom44=95\).
  3. 경우 \(\{4,16\}\): 잔여류 4개가 각각 (공차4/공차16) 독립 선택 \(\Rightarrow 2^4=16\).
  4. 경우 \(\{1,4\}\): \(\{1,16\}\)과 같은 합성 카운트 \(\Rightarrow 95\).
  5. 합 \(95+16+95=206\)에서 한 종류만 쓰는 분할 \(3\)개를 중복으로 빼 \(\Rightarrow 203\).
  6. 유윤제는 \(45\): 세 경우로 나누는 구조를 놓침 — 아래 심화 해설 참고.
→ 공식 해설 (문제 10)

심화 — 10번: 경우 나누기 + 합성(composition) 세기

  1. 구조 파악: 세 공차 \(1,4,16\)을 동시에 쓰는 분할은 모순이 생겨 불가능하다. 따라서 실제로는 두 공차만 쓰는 \(\{1,16\},\{4,16\},\{1,4\}\) 세 경우뿐 — 문제를 작은 세 조각으로 쪼개는 것이 핵심.
  2. 합성 세기: 경우 \(\{1,16\}\)에서 \(1\sim16\) 구간을 '공차1 블록(길이 4)'과 '공차16 자리(4개 묶음)'로 어떻게 배열하느냐가 전체 분할을 결정한다. 이는 \(16\)을 부품 \(1\)과 \(4\)로 만드는 순서 있는 합성의 수 \(=95\)와 같다.
  3. 나머지 두 경우: \(\{4,16\}\)은 잔여류 \(4\)개가 독립적으로 둘 중 하나를 골라 \(2^4=16\); \(\{1,4\}\)는 다시 합성 카운트 \(95\).
  4. 포함–배제: \(95+16+95=206\)에서 '한 공차만 쓰는' 분할 \(3\)개가 두 경우에 중복으로 세어졌으니 빼서 \(\mathbf{203}\). — 같은 대상을 두 번 세지 않았는지 항상 점검할 것.
연습문제 1. 부품 \(1\)과 \(4\)만으로 \(16\)을 만드는 순서 있는 합성의 수를 구하라. (예: \(4{+}4{+}4{+}4\), \(1{+}1{+}\cdots{+}1\), \(4{+}1{+}\cdots\))
해설 보기
  1. \(4\)를 \(k\)개 쓰면 \(1\)은 \(16-4k\)개, 항의 총수는 \(16-3k\)개.
  2. 그 자리에 \(4\)를 놓는 방법 \(\binom{16-3k}{k}\): \(k=0,1,2,3,4\) → \(1,13,45,35,1\).
  3. \(\therefore 1+13+45+35+1=\mathbf{95}\) — 10번의 핵심 카운트와 정확히 같다.
연습문제 2. 부품 \(1\)과 \(2\)만으로 \(8\)을 만드는 순서 있는 합성의 수를 구하라.
해설 보기
  1. 마지막 항이 \(1\) 또는 \(2\)이므로 \(g(n)=g(n-1)+g(n-2)\).
  2. \(g(1),g(2),\dots=1,2,3,5,8,13,21,34\) (피보나치).
  3. \(\therefore g(8)=\mathbf{34}.\)
