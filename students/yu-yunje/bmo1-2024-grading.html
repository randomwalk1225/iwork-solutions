Question

We say that the positive integer \(n \ge 3\) is happy if it is possible to arrange \(n\) different positive integers in a circle such that two conditions are satisfied:

(a) If integers \(u\) and \(v\) in the circle are neighbours, then either \(u\) divides \(v\) or \(v\) divides \(u\);

(b) If different integers \(u\) and \(v\) are in the circle but are not neighbours, then neither divides the other.

Determine, with proof, which positive integers \(n\) in the range \(3 \le n \le 12\) are happy.

Student’s work
“The case n=3 is unusual because every number is adjacent to every other, so Condition b does not need to be considered.
For even values of n>4 we can show that n is happy by placing distinct primes in alternate spaces and placing the products of neighbouring primes between them as in the examples below.”
Three circle diagrams — n=3: (1, 4, 2); n=6: (10, 2, 6, 3, 15, 5); n=8: (14, 2, 6, 3, 15, 5, 35, 7). No diagrams for n=10 or n=12.
“Thus if n>3 is odd, n is not happy. So the required are 3, 4, 6, 8, 10 and 12.”
Assessment

The final answer is correct: 3, 4, 6, 8, 10 and 12.

Missing 1 — the proof that odd \(n \gt 3\) is not happy. Only the concluding sentence appears. The official argument: for consecutive numbers \(a, b, c\) round the circle, \(a \lt b \lt c\) would force \(a \mid b\) and \(b \mid c\), hence \(a \mid c\) — impossible, as \(a\) and \(c\) are not neighbours. So \(\lt\) and \(\gt\) signs must alternate round the circle, and an odd number of signs cannot alternate.

Missing 2 — the special case \(n = 4\). The construction used (distinct primes in alternate spaces) fails for \(n = 4\): with primes \(p_1, p_2\), both remaining numbers would equal \(p_1 p_2\). The official solution adapts it to \(p_1^2 p_2\) and \(p_1 p_2^2\), e.g. 2, 12, 3, 18. The circles for \(n = 10\) and \(n = 12\) are also absent.

From the markers’ comments: “Others gave constructions for the happy numbers … and then said that since this construction doesn’t work for the remaining odds that they are therefore not happy. This is also erroneous, as other constructions might be possible.”

Official solution (UKMT Markers’ Report)
  1. \(n = 3\) is unusual: every number is adjacent to every other, so condition (b) does not need to be considered — e.g. (1, 4, 2).
  2. Even \(n \gt 4\): place distinct primes in alternate spaces and the products of neighbouring primes between them. \(n=6\): (10, 2, 6, 3, 15, 5); \(n=8\): (14, 2, 6, 3, 15, 5, 35, 7); \(n=10\): (22, 2, 6, 3, 15, 5, 35, 7, 77, 11); \(n=12\): (26, 2, 6, 3, 15, 5, 35, 7, 77, 11, 143, 13).
  3. \(n = 4\): the construction above fails, so multiply the two composites by different numbers neither of which divides the other: 2, 12, 3, 18.
  4. Odd \(n \gt 3\): for consecutive \(a, b, c\), an ordering \(a \lt b \lt c\) implies \(a \mid c\), contradicting condition (b); likewise \(a \gt b \gt c\). So \(\lt\) and \(\gt\) must alternate round the circle, which is impossible for an odd number of signs. Hence odd \(n \gt 3\) is not happy.
  5. Answer: 3, 4, 6, 8, 10, 12.

Question

A magician performs a trick with a deck of \(n\) cards that are numbered from 1 to \(n\). The magician prepares for the trick by putting the cards in an order of her choosing. Then she challenges a member of the audience to write an integer on a board. The magician turns over the cards one by one, in their pre-arranged order. Every time the magician turns over a card, the audience member multiplies the number on the board by \(-1\), adds it to the number on the card, writes the result on the board, and erases the old number. The magician guarantees that, no matter which initial integer is chosen, the initial and final numbers will sum to 0.

Determine for which natural numbers \(n\) the magician can perform the trick. You must both prove that the trick is possible for the numbers you claim, and prove that it is not possible for any other numbers.

Student’s work
The board numbers expanded in sequence:
\(x\) → \(a_1-x\) → \(a_2-(a_1-x)=a_2-a_1+x\) → … → \(a_n-a_{n-1}+a_{n-2}-\cdots+(-1)^n x\)
“When x is added to this final number the result must be zero. \(a_n+a_{n-2}+a_{n-4}=a_{n-1}+a_{n-3}\cdots\) So the trick can be performed if and only if n is odd and it is possible to divide the number into two sets, of size \(\frac{n-1}{2}\), \(\frac{n+1}{2}\) respectively.
For n=7 in the order 1, 3, 4, 5, 7, 6 makes the final −x.
Thus the trick can be performed for all n = 4k+3”
Assessment

The final answer is correct: \(n = 4k + 3\).

Missing 1 — “each of which has the same sum”. The submission stops at dividing \(1, 2, \dots, n\) into two sets of sizes \(\tfrac{n-1}{2}\) and \(\tfrac{n+1}{2}\). Size alone is no condition at all — any \(n\) can be divided that way. The official solution requires the two sets to have equal sums, and the next line depends on it.

Missing 2 — deriving \(4k + 3\). The common sum must be \(\tfrac12(1 + 2 + \cdots + n) = \tfrac{n(n+1)}{4}\), and for odd \(n\) this is an integer only if \(n + 1\) is divisible by 4. The submission states only the conclusion. From the markers’ comments: “This step is not obvious and requires justification.”

Missing 3 — the construction. The above is only the necessity half. For possibility: \(n = 3\) works with 1, 3, 2, and if \(n = m\) works then appending \(m+1, m+2, m+4, m+3\) makes \(n = m + 4\) work (the four added terms cancel), so induction covers all \(n = 4k + 3\).

A transcription slip: the \(n = 7\) order is written as 1, 3, 4, 5, 7, 6 — six cards; the 2 is missing. The official order 1, 3, 2, 4, 5, 7, 6 gives \((6-7+5-4) + (2-3+1-x) = -x\); as written, the result is not \(-x\).

Official solution (UKMT Markers’ Report)
  1. With initial number \(x\) and cards \(a_1, \dots, a_n\) in turned order, the final number on the board is \(a_n - a_{n-1} + a_{n-2} - \cdots + (-1)^n x\).
  2. Adding \(x\) must give zero, and \(x\) can be any integer, so \((-1)^n x + x = 0\): \(n\) is odd.
  3. We also need \(a_n + a_{n-2} + \cdots = a_{n-1} + a_{n-3} + \cdots\) — that is, \(1, \dots, n\) must split into two sets of sizes \(\tfrac{n+1}{2}\) and \(\tfrac{n-1}{2}\), each of which has the same sum.
  4. The common sum is \(\tfrac12(1 + 2 + \cdots + n) = \tfrac{n(n+1)}{4}\). Since \(n\) is odd, this is an integer only if \(4 \mid n + 1\): the trick is impossible unless \(n = 4k + 3\).
  5. Possibility — \(n = 3\): the order 1, 3, 2 gives \(2 - 3 + 1 - x = -x\). \(n = 7\): 1, 3, 2, 4, 5, 7, 6. In general, if \(n = m\) works, append \(m+1, m+2, m+4, m+3\): the final number changes by \((m+3)-(m+4)+(m+2)-(m+1) = 0\). By induction the trick works for all \(n = 4k + 3\).

Question

Rhian and Jack are playing a game in which initially the number \(10^6\) is written on a blackboard. If the current number on the board is \(n\), a move consists of choosing two different positive integers \(a, b\) such that \(n = ab\) and replacing \(n\) with \(|a - b|\). Rhian starts, then the players make moves alternately. A player loses if they are unable to move.

Determine, with proof, which player has a winning strategy.

Student’s work
Not submitted.
Assessment

Not attempted (the student reported not knowing how to approach Questions 3 and 6).

From the markers’ comments: “Problem 3 (as well as problem 1) provided the annual reminder of the importance of trying small examples. Candidates who considered what happens when the game is played starting with 2, then 3, then 4 and so on generally spotted the importance of parity and many went on to solve the problem. Those who dived in with an initial value of one million often missed the point.”

Official solution (UKMT Markers’ Report)
  1. \(10^6\) is even, so Rhian (the first player) has a winning strategy.
  2. Rhian can always hand Jack an odd number: given even \(n\), take \(n = n \times 1\), and \(|n - 1|\) is odd.
  3. Jack, holding an odd number, can only factorise it as odd \(\times\) odd (an odd number has no even factors), and the difference of two odd numbers is even — so Jack must always return an even number.
  4. The board value strictly decreases (\(|a - b| \lt n\) whenever \(ab = n\)), so eventually Rhian hands Jack the number 1, which cannot be written as a product of two different positive integers. Jack cannot move and loses.

Question

In the acute-angled triangle \(ABC\) we have \(AB \lt AC \lt BC\). The midpoint of \(BC\) is \(M\). There is a point \(P\) on the line segment \(AM\) such that \(AB = CP\), and \(\angle PAB = \angle BCP\). Prove that \(\angle CPB = 90^\circ\).

Student’s work
“Step 1: Introduce a new point which helps you use the given conditions
2: Use the new point and the given conditions to find some equal angles
3: Conclude that M is the centre of the circumcircle of CPB, \(\angle CPB = 90^\circ\)
4. Reflect P in the point M to get Q   \(\angle QAB = \angle CPQ = \angle MCP\)
3. Now \(\triangle MCP\) is a isoceles, \(MB = MP = MC\)
4: This yields that M is the centre of the circle CPB with diameter BC and \(\angle CPB = 90^\circ\) since the angle in a semicircle is a right angle.”
Assessment

The skeleton of the proof is all there. The first three lines are a plan; the actual proof begins at “Reflect P in the point M to get Q” — the construction (Step 1), the angle equalities \(\angle QAB = \angle CPQ = \angle MCP\) (the conclusions of Step 2), the isosceles triangle with \(MB = MP = MC\) (Step 3), and the diameter/semicircle conclusion (Step 4). This is the same route as the official solution.

What is missing is the justification of the angle equalities. They are asserted, not proved. The official route: the diagonals of \(BQCP\) bisect each other, so it is a parallelogram; then \(PC = BQ = AB\) makes \(\triangle ABQ\) isosceles with \(\angle QAB = \angle BQA\), and \(PC \parallel BQ\) gives \(\angle BQP = \angle CPQ = \angle MCP\). Without this paragraph, “Now \(\triangle MCP\) is isosceles” has no basis. The marks hinge on exactly this linking argument: the construction and the route are credited; the missing justification is not.

The final line does name the theorem used (“angle in a semicircle”). The markers’ report notes that marks were lost where such theorems were used implicitly — this part is done as required.

Official solution (UKMT Markers’ Report)
  1. Step 1 — Reflect \(P\) in the point \(M\) to get the point \(Q\).
  2. Step 2 — The diagonals of \(BQCP\) bisect each other, so it is a parallelogram. We have \(PC = BQ = AB\), so \(\triangle ABQ\) is isosceles and \(\angle QAB = \angle BQA\). Since \(PC \parallel BQ\), \(\angle BQP = \angle CPQ = \angle MCP\).
  3. Step 3 — Now \(\triangle MCP\) is isosceles, and we see that \(MB = MP = MC\).
  4. Step 4 — This yields that \(M\) is the centre of the circle \(CPB\) with diameter \(BC\), and \(\angle CPB = 90^\circ\) since the angle in a semicircle is a right angle.
  5. Alternative — the Sine Rule on \(\triangle MAB\) and \(\triangle PMC\): \(\frac{BM}{\sin\angle MAB} = \frac{AB}{\sin\angle BMA} = \frac{PC}{\sin\angle PMC} = \frac{PM}{\sin\angle MCP}\) (the middle equality from \(AB = PC\) and \(\angle BMA + \angle PMC = 180^\circ\)). Since \(\angle MAB = \angle MCP\), \(BM = PM\), and the conclusion follows as above.

Question

Let \(p\) be a prime number, and let \(n\) be the smallest positive integer, strictly greater than 1, for which \(n^6 - 1\) is divisible by \(p\). Prove that at least one of \((n+1)^6 - 1\) and \((n+2)^6 - 1\) is divisible by \(p\).

Student’s work
“We begin by noting that \(n^6-1 = (n^3)^2-1\)
\(n^6-1 = (n^3-1)(n^3+1)\)
\(n^6-1 = (n-1)(n^2+n+1)(n+1)(n^2-n+1)\)
\(p\) does not divide \((n-1)^6-1 = (n-2)(n^2-n+1)(n)(n^2-3n+3)\)
\(p\) does not divide \((n-2)^6-1 = (n-3)(n^2-3n+3)(n-1)(n^2-5n+7)\)
In the first of these case we see that \(p\) divides \((n+1)^6-1 = n(n^2+3n+3)(n+2)(n^2+n+1)\)
in the second case \(p\) divides \((n+2)^6-1 = (n+1)(\cdots)(n+3)(n^2+3n+3)\)
We also note that \(4^6-1 = 4095 = 5\times819 = 5\times9\times91 = 13\times3\cdots\) \(4^6-1\) required”
Assessment

Missing 1 — the sentence between the two “does not divide” lines and the conclusion. After stating that \(p\) divides neither \((n-1)^6 - 1\) nor \((n-2)^6 - 1\), the submission jumps straight to “In the first of these case…” But what these refers to has not yet been established. The official solution has, in between: “for the least \(n \gt 1\) we must have either \(p \mid (n^2 + n + 1)\) or \(p \mid (n + 1)\)”. This sentence is the axis of the proof — it is where the minimality of \(n\) narrows four factors down to two, and it is what gives the two “cases” their meaning.

Missing 2 — the assumption \(n \gt 3\) and the small cases. The argument needs \(n - 2 \gt 1\), i.e. \(n \gt 3\), which is nowhere stated, and \(n = 2\), \(n = 3\) are not checked. Official finish: \(n = 2\) gives \(63 = 3^2 \times 7\), so \(p = 3, 7\), verified by \(3 \mid 4^6 - 1\) and \(7 \mid 3^6 - 1\); \(n = 3\) gives \(728 = 2^3 \times 7 \times 13\), so \(p = 2, 13\), verified by \(2 \mid 5^6 - 1\) and \(13 \mid 4^6 - 1\).

The final line’s factorisation of 4095 belongs to exactly that \(n = 3\) check, but with the case analysis absent it is left hanging. The four factorisation lines themselves are all correct.

Official solution (UKMT Markers’ Report)
  1. \(n^6 - 1 = (n^3)^2 - 1 = (n^3 - 1)(n^3 + 1) = (n-1)(n^2+n+1)(n+1)(n^2-n+1)\).
  2. \(p \mid n^6 - 1\), so \(p\) divides one of these four factors.
  3. Since \(n\) is minimal, provided \(n \gt 3\), \(p\) divides neither \((n-1)^6 - 1 = (n-2)(n^2-n+1)\,n\,(n^2-3n+3)\) nor \((n-2)^6 - 1 = (n-3)(n^2-3n+3)(n-1)(n^2-5n+7)\).
  4. These imply that for the least \(n \gt 1\) we must have either \(p \mid (n^2 + n + 1)\) or \(p \mid (n + 1)\).
  5. In the first case \(p \mid (n+1)^6 - 1 = n(n^2+3n+3)(n+2)(n^2+n+1)\); in the second case \(p \mid (n+2)^6 - 1 = (n+1)(n^2+5n+7)(n+3)(n^2+3n+3)\).
  6. Small cases — \(n = 2\): \(63 = 3^2 \times 7\), so \(p = 3, 7\); \(3 \mid 4^6 - 1\) and \(7 \mid 3^6 - 1\). \(n = 3\): \(728 = 2^3 \times 7 \times 13\), so \(p = 2, 13\); \(2 \mid 5^6 - 1\) and \(4^6 - 1 = 4095 = 3^2 \times 5 \times 7 \times 13\), so \(13 \mid 4^6 - 1\).

Question

Björk has 64 sugar cubes, all of size \(1\times1\times1\). Each sugar cube is either white or demerara or muscovado in flavour. She piles the sugar cubes into a neat \(4\times4\times4\) cube.

Prove that there must be 12 sugar cubes of the same flavour which can be put into 6 disjoint pairs so that the distance between the centres of the cubes in each pair is the same.

Student’s work
Not submitted.
Assessment

Not attempted (the student reported not knowing how to approach Questions 3 and 6).

From the markers’ comments: “Problem 6 proved hard enough to ensure that almost all candidates had something to think about throughout the exam.” From the paper’s instructions (no. 3): “One complete solution will gain more credit than several unfinished attempts. It is more important to complete a small number of questions than to try all the problems.”

Official solution (UKMT Markers’ Report)
  1. Split the \(4\times4\times4\) cube into eight disjoint \(2\times2\times2\) subcubes.
  2. Each subcube splits into two sets of four cubes whose centres form the vertices of a regular tetrahedron of edge length \(\sqrt{2}\). By the pigeonhole principle, two of the four vertices of each tetrahedron share a flavour — giving 16 same-flavour pairs, all at distance \(\sqrt{2}\).
  3. By the extended pigeonhole principle, one of the three flavours accounts for at least six of these 16 pairs (\(16 \gt 5 \times 3\)). The subcubes are disjoint, so the six pairs are disjoint.

  • 빠진 자리가 네 문항 모두 같다 — 점수가 걸린 핵심 단계. 1번 홀수 불가능 증명과 \(n=4\) 구성, 2번 \(n(n+1)/4\) 정수 조건과 구성, 4번 각 등식 \(\angle QAB = \angle CPQ = \angle MCP\) 의 근거, 5번 “\(p \mid n^2+n+1\) 또는 \(p \mid n+1\)” 한 문장. 결론과 답은 있고 그 사이를 잇는 논증만 없다.
  • 점수는 제출 답안을 UKMT 공식 채점 기준에 대어 매긴 추정이다. 감점 근거는 문항마다 채점자 리포트 원문을 인용했다.
  • 학부모 전언 — “3시간 30분간 시간 재서 풀었고, 6문제 중 3번과 6번은 모르겠다고 합니다. 4번은 답은 맞았는데 풀이는 맞는지 모르겠다고 합니다. 풀이도 종이에 잘 쓰는 것도 연습을 해야 할 것 같습니다.”

다시 볼 내용

  • “어느 것이 성립하는가” 문항의 두 축 (1번) — 성립하는 것의 구성 과 나머지의 불가능 증명. 한 축만 있으면 나머지가 채워지지 않는다. “내 구성법이 안 통한다” 는 불가능의 증명이 아니다.
  • 필요조건과 충분조건 (2번) — “\(4k+3\) 이 아니면 안 된다” 와 “\(4k+3\) 이면 된다” 는 다른 명제다. 뒤쪽은 구성이나 귀납으로 보인다.
  • 기하는 각 추적이 몸통이다 (4번) — “이등변이므로” 앞에 어느 각이 어느 각과 왜 같은지가 와야 한다. 사용된 정리는 이름을 밝힌다.
  • “최소” 조건을 쓰는 자리 (5번) — 더 작은 값에서 안 된다는 사실로 경우를 좁힌다. 그 문장이 증명의 축이다.
  • 작은 경우부터 해 본다 (3번) — 채점자 리포트가 이 문항과 1번에 대해 직접 적은 조언이다. \(10^6\) 으로 바로 들어가면 막힌다.

문제

양의 정수 \(n \ge 3\) 이 happy 하다는 것은, 서로 다른 양의 정수 \(n\) 개를 원형으로 배열해 다음 두 조건을 만족시킬 수 있다는 뜻이다.

(a) 원 안의 두 정수 \(u\), \(v\) 가 이웃이면 \(u \mid v\) 또는 \(v \mid u\) 이다.

(b) 서로 다른 \(u\), \(v\) 가 이웃이 아니면 어느 쪽도 다른 쪽을 나누지 않는다.

\(3 \le n \le 12\) 인 양의 정수 가운데 어느 것이 happy 한지 증명과 함께 결정하라.

학생 답안
“The case n=3 is unusual because every number is adjacent to every other, so Condition b does not need to be considered.
For even values of n>4 we can show that n is happy by placing distinct primes in alternate spaces and placing the products of neighbouring primes between them as in the examples below.”
원 그림 세 개 — n=3 은 (1, 4, 2), n=6 은 (10, 2, 6, 3, 15, 5), n=8 은 (14, 2, 6, 3, 15, 5, 35, 7). n=10, n=12 그림은 없다.
“Thus if n>3 is odd, n is not happy. So the required are 3, 4, 6, 8, 10 and 12.”
부분 답 3·4·6·8·10·12 는 정답. 점수가 걸린 두 축 가운데 불가능 증명이 통째로 없다.
틀린 지점과 올바른 답

답은 맞다. 3 · 4 · 6 · 8 · 10 · 12.

빠진 것 1 — 홀수 \(n>3\) 이 happy 가 아니라는 증명. 답안에는 결론 문장만 있다. 공식 해답의 논증은 이렇다. 원 위에 이웃한 세 수를 \(a, b, c\) 라 하자. \(a < b < c\) 이면 \(a \mid b\), \(b \mid c\) 이므로 \(a \mid c\) 인데, \(a\) 와 \(c\) 는 이웃이 아니므로 조건 (b)에 어긋난다. \(a > b > c\) 도 같은 이유로 안 된다. 따라서 원 둘레에 부등호를 적으면 \(<\) 와 \(>\) 가 번갈아 나와야 하는데, 홀수 개의 기호는 원에서 번갈아 놓일 수 없다.

빠진 것 2 — \(n=4\) 특수 구성. 답안의 구성법(소수를 한 칸 걸러 놓고 사이에 이웃한 두 소수의 곱을 넣는다)은 \(n=4\) 에서 안 된다. 소수 \(p_1\), \(p_2\) 만 쓰면 나머지 두 자리가 모두 \(p_1 p_2\) 가 되어 “서로 다른” 조건을 어기기 때문이다. 공식 해답은 \(p_1^2 p_2\) 와 \(p_1 p_2^2\) 로 바꿔 해결한다 — 예: 2, 12, 3, 18.

채점자 리포트가 이 문항의 감점 사유로 명시한 것 (원문):

“Some proved that odds (other than 3) cannot be happy, and commented that the remaining numbers are therefore happy, implicitly using the erroneous reasoning that anything not yet proven unhappy must be happy. Others gave constructions for the happy numbers … and then said that since this construction doesn’t work for the remaining odds that they are therefore not happy. This is also erroneous, as other constructions might be possible.”

이 문항은 구성(happy 임을 보임) 과 불가능 증명(happy 가 아님을 보임) 두 축이고, 한 축만 있으면 나머지는 채워지지 않는다. 답안에는 구성 쪽만, 그것도 \(n=10, 12\) 를 뺀 채로 있다.

공식 해답 (UKMT 채점자 리포트)
  1. happy 한 것 — \(n=3\) 은 모든 수가 서로 이웃이라 조건 (b)를 따질 필요가 없다. 예: (1, 4, 2).
  2. 짝수 \(n>4\) — 서로 다른 소수를 한 칸 걸러 놓고, 그 사이에 이웃한 두 소수의 곱을 넣는다. \(n=6\): (10, 2, 6, 3, 15, 5) / \(n=8\): (14, 2, 6, 3, 15, 5, 35, 7) / \(n=10\): (22, 2, 6, 3, 15, 5, 35, 7, 77, 11) / \(n=12\): (26, 2, 6, 3, 15, 5, 35, 7, 77, 11, 143, 13).
  3. \(n=4\) — 위 구성이 안 되므로 두 합성수에 서로 나누지 않는 수를 곱한다: 2, 12, 3, 18.
  4. happy 가 아닌 것 — 이웃한 세 수 \(a, b, c\) 에서 \(a<b<c\) 면 \(a \mid c\) 가 되어 조건 (b) 위반. 따라서 원 둘레의 부등호가 번갈아 나와야 하는데 홀수 개는 원에서 번갈아 놓을 수 없다. \(\Rightarrow\) 홀수 \(n>3\) 은 happy 가 아니다.
  5. 답: 3, 4, 6, 8, 10, 12.
이 문항이 가르치는 것
  • “어느 것이 성립하는가” 문항은 성립하는 것의 구성 + 나머지의 불가능 증명 두 축이다
  • “내 구성법이 안 통한다”는 불가능의 증명이 아니다 — 다른 구성이 있을 수 있다. \(n=4\) 가 바로 그 반례다
  • 원형 배열에서 부등호가 번갈아 나오면 개수는 짝수 — 되풀이 쓰이는 논증

문제

마술사가 1부터 \(n\) 까지 번호가 붙은 카드 \(n\) 장으로 마술을 한다. 마술사가 카드 순서를 정해 둔 뒤 관객에게 정수 하나를 칠판에 쓰게 한다. 마술사가 카드를 정해진 순서로 한 장씩 뒤집을 때마다, 관객은 칠판의 수에 \(-1\) 을 곱하고 카드의 수를 더해 그 결과를 새로 쓰고 옛 수를 지운다. 마술사는 처음 어떤 정수를 골라도 처음 수와 마지막 수의 합이 0 이 된다고 장담한다.

이 마술이 가능한 자연수 \(n\) 을 모두 구하라. 주장하는 \(n\) 에서 가능함과, 그 밖의 \(n\) 에서 불가능함을 둘 다 증명해야 한다.

학생 답안
칠판의 수를 차례로 전개했다.
\(x\) → \(a_1-x\) → \(a_2-(a_1-x)=a_2-a_1+x\) → … → \(a_n-a_{n-1}+a_{n-2}-\cdots+(-1)^n x\)
“When x is added to this final number the result must be zero. \(a_n+a_{n-2}+a_{n-4}=a_{n-1}+a_{n-3}\cdots\) So the trick can be performed if and only if n is odd and it is possible to divide the number into two sets, of size \(\frac{n-1}{2}\), \(\frac{n+1}{2}\) respectively.
For n=7 in the order 1, 3, 4, 5, 7, 6 makes the final −x.
Thus the trick can be performed for all n = 4k+3”
부분 답 \(n=4k+3\) 은 정답. 그 답이 왜 나오는지의 두 단계가 없다.
틀린 지점과 올바른 답

답은 맞다. \(n = 4k+3\).

빠진 것 1 — 두 집합의 합이 같아야 한다는 조건. 답안은 “크기가 \(\frac{n-1}{2}\), \(\frac{n+1}{2}\) 인 두 집합으로 나눌 수 있으면” 에서 멈춘다. 크기만으로는 아무 조건도 되지 않는다 — 어떤 \(n\) 이든 그렇게 나눌 수 있다. 공식 해답은 each of which has the same sum 을 붙인다. 이 말이 있어야 다음 줄이 성립한다.

빠진 것 2 — \(4k+3\) 의 유도. 답안에는 결론만 있다. 공식 해답의 두 줄은 이렇다. 두 집합의 공통 합은 \(\tfrac12(1+2+\cdots+n) = \frac{n(n+1)}{4}\) 이어야 하고, \(n\) 이 홀수이므로 이 값이 정수가 되려면 \(n+1\) 이 4의 배수 여야 한다. 곧 \(n = 4k+3\).

빠진 것 3 — 가능함의 증명(구성). 위까지는 “\(4k+3\) 이 아니면 불가능” 이라는 필요조건일 뿐이다. \(4k+3\) 이면 실제로 된다는 것을 따로 보여야 한다. 공식 해답은 \(n=3\) 에서 1, 3, 2 로 시작해, \(n=m\) 에서 되면 \(m+1, m+2, m+4, m+3\) 네 장을 그 순서로 덧붙여 \(n=m+4\) 에서도 된다(덧붙인 네 장의 교대합이 0)는 귀납으로 마무리한다.

옮겨 적다 생긴 오류. \(n=7\) 배열이 1, 3, 4, 5, 7, 6 으로 여섯 장이다. 숫자 2가 빠졌다. 공식 해답은 1, 3, 2, 4, 5, 7, 6(일곱 장)이고, 그대로 계산해야 \((6-7+5-4)+(2-3+1-x) = -x\) 가 된다. 적힌 대로 계산하면 \(-x\) 가 나오지 않는다.

채점자 리포트가 이 문항의 감점 사유로 명시한 것 (원문):

“A common gap was to state that: for odd \(n\), if \(1+2+\cdots+n\) is even (or if \(n = 4k+3\)), then the trick can be performed. This step is not obvious and requires justification.”

공식 해답 (UKMT 채점자 리포트)
  1. 처음 수를 \(x\), 뒤집는 순서를 \(a_1, \dots, a_n\) 이라 하면 칠판의 마지막 수는 \(a_n - a_{n-1} + a_{n-2} - \cdots + (-1)^n x\) 다.
  2. 여기에 \(x\) 를 더해 0 이 되어야 하고, \(x\) 는 어떤 정수든 될 수 있으므로 \((-1)^n x + x = 0\) 이어야 한다. \(\Rightarrow\) \(n\) 은 홀수.
  3. 동시에 \(a_n + a_{n-2} + \cdots = a_{n-1} + a_{n-3} + \cdots\) 여야 한다. 곧 \(1, \dots, n\) 을 크기 \(\frac{n+1}{2}\) 과 \(\frac{n-1}{2}\) 인 두 집합으로 나누되 두 집합의 합이 같아야 한다.
  4. 공통 합 \(= \tfrac12(1+2+\cdots+n) = \frac{n(n+1)}{4}\). \(n\) 이 홀수이므로 이 값이 정수이려면 \(4 \mid n+1\). \(\Rightarrow\) \(n = 4k+3\) 이 아니면 불가능.
  5. 가능함 — \(n=3\): 1, 3, 2 \(\Rightarrow\) \(2-3+1-x = -x\). \(n=7\): 1, 3, 2, 4, 5, 7, 6. 일반적으로 \(n=m\) 에서 되면 \(m+1, m+2, m+4, m+3\) 을 그 순서로 덧붙여도 마지막 수가 바뀌지 않는다(\((m+3)-(m+4)+(m+2)-(m+1)=0\)). 귀납으로 모든 \(4k+3\) 에서 된다.
이 문항이 가르치는 것
  • 필요조건과 충분조건은 각각 증명해야 한다. “\(4k+3\) 이 아니면 안 된다” 를 보인 것은 절반이다. “\(4k+3\) 이면 된다” 는 구성으로 보인다
  • “나눌 수 있다” 같은 조건은 무엇이 같아야 하는지까지 적어야 조건이 된다
  • \(n \to n+4\) 귀납은 이 유형에서 되풀이 쓰인다 — 덧붙이는 덩어리의 교대합을 0 으로 만든다
3 미응답 게임 이론 · 패리티

문제

칠판에 처음 \(10^6\) 이 적혀 있다. 현재 수가 \(n\) 일 때 한 수는, 서로 다른 양의 정수 \(a, b\) 를 \(n = ab\) 가 되게 골라 \(n\) 을 \(|a-b|\) 로 바꾸는 것이다. Rhian 이 먼저 두고 번갈아 둔다. 둘 수 없는 사람이 진다. 어느 쪽에 필승 전략이 있는지 증명과 함께 결정하라.

학생 답안
제출하지 않았다.
미응답 미제출. 학부모 전언 — “3번과 6번은 모르겠다고 합니다.”
틀린 지점과 올바른 답

채점자 리포트가 이 문항에 대해 남긴 말 (원문):

“Problem 3 (as well as problem 1) provided the annual reminder of the importance of trying small examples. Candidates who considered what happens when the game is played starting with 2, then 3, then 4 and so on generally spotted the importance of parity and many went on to solve the problem. Those who dived in with an initial value of one million often missed the point.”

\(10^6\) 으로 바로 들어가면 경우가 갈려 막힌다. 2, 3, 4, 5 부터 직접 두어 보면 패리티가 보인다.

공식 해답 (UKMT 채점자 리포트)
  1. \(10^6\) 은 짝수이므로 Rhian(선수)에게 필승 전략이 있다.
  2. Rhian 은 언제나 홀수를 넘겨 주면 된다. 짝수 \(n\) 을 받았을 때 \(n = n \times 1\) 로 두면 \(|n-1|\) 이 홀수다.
  3. 홀수를 받은 Jack 은 홀수 \(\times\) 홀수 로만 인수분해할 수 있다(홀수는 짝수 약수가 없다). 홀수끼리의 차는 언제나 짝수이므로, Jack 은 늘 짝수를 되돌려 줄 수밖에 없다.
  4. Rhian 은 계속 홀수를 넘기다가 마침내 1 을 넘긴다. 1 은 서로 다른 두 양의 정수의 곱으로 쓸 수 없으므로 Jack 은 둘 수 없고 진다.
이 문항이 가르치는 것
  • 작은 경우부터 직접 해 본다. 2, 3, 4, 5 로 두어 보면 패리티가 드러난다. 큰 수로 바로 들어가면 경우 분석에 빠진다
  • 게임 문제의 표준 뼈대 — 한쪽만 만들 수 있는 상태를 찾고, 상대가 그 상태를 깰 수 없음을 보인다
4 부분 평면기하 · 보조점과 각 추적
3 / 10점
문제

예각삼각형 \(ABC\) 에서 \(AB < AC < BC\) 이고 \(BC\) 의 중점을 \(M\) 이라 하자. 선분 \(AM\) 위의 점 \(P\) 가 \(AB = CP\) 이고 \(\angle PAB = \angle BCP\) 를 만족한다. \(\angle CPB = 90^\circ\) 임을 증명하라.

학생 답안
“Step 1: Introduce a new point which helps you use the given conditions
2: Use the new point and the given conditions to find some equal angles
3: Conclude that M is the centre of the circumcircle of CPB, \(\angle CPB = 90^\circ\)
4. Reflect P in the point M to get Q   \(\angle QAB = \angle CPQ = \angle MCP\)
3. Now \(\triangle MCP\) is a isoceles, \(MB = MP = MC\)
4: This yields that M is the centre of the circle CPB with diameter BC and \(\angle CPB = 90^\circ\) since the angle in a semicircle is a right angle.”
부분 보조점 \(Q\) 작도부터 결론까지 증명의 뼈대는 다 적었다. 축이 되는 각 등식 \(\angle QAB = \angle CPQ = \angle MCP\) 를 선언만 하고 근거를 적지 않았다.
틀린 지점과 올바른 답

증명의 뼈대는 처음부터 끝까지 있다. 앞 세 줄은 풀이 계획이고, “Reflect P in the point M to get Q” 부터가 실제 증명이다 — \(Q\) 작도(Step 1), 각 등식 \(\angle QAB = \angle CPQ = \angle MCP\) (Step 2의 결론), \(\triangle MCP\) 이등변과 \(MB = MP = MC\) (Step 3), 지름 \(BC\) 와 반원의 원주각으로 마무리(Step 4). 공식 해답과 같은 경로다.

빠진 것 — 각 등식의 근거. \(\angle QAB = \angle CPQ = \angle MCP\) 는 이 증명의 축인데, 답안은 이 등식을 선언만 하고 왜 성립하는지를 적지 않았다. 공식 해답이 이 등식을 얻는 길은 이렇다.

\(BQCP\) 의 두 대각선이 서로를 이등분하므로 \(BQCP\) 는 평행사변형이다. 따라서 \(PC = BQ\) 인데 \(PC = AB\) 이므로 \(BQ = AB\), 곧 \(\triangle ABQ\) 가 이등변이고 \(\angle QAB = \angle BQA\). 또 \(PC \parallel BQ\) 이므로 \(\angle BQP = \angle CPQ = \angle MCP\).

이 문단이 없으면 다음 줄의 “Now \(\triangle MCP\) is isosceles” 가 어디서 나온 말인지 근거가 없다. 채점은 이 근거에 걸린다 — 작도와 경로 제시는 인정되고, 잇는 논증이 없어 점수가 깎인다.

채점자 리포트의 감점 사유 (원문) — 이 문항에서 특히 자주 깎였다.

“Approaches of this nature lost marks where theorems (such as the ‘angle in a semicircle’ theorem) were used implicitly rather than being clearly stated. Similarly, marks were deducted when a solution depended on the order of points along a line but failed to justify it.”

답안의 마지막 줄은 “since the angle in a semicircle is a right angle” 라고 정리를 명시했다. 이 부분은 리포트가 요구하는 대로 되어 있다.

학생 자기 평가와 겹친다. 학부모 전언 — “4번은 답은 맞았는데 풀이는 맞는지 모르겠다고 합니다.”

공식 해답 (UKMT 채점자 리포트)
  1. Step 1 — \(P\) 를 점 \(M\) 에 대해 대칭시켜 \(Q\) 를 잡는다.
  2. Step 2 — \(BQCP\) 의 대각선이 서로를 이등분하므로 평행사변형이다. \(PC = BQ = AB\) 이므로 \(\triangle ABQ\) 는 이등변이고 \(\angle QAB = \angle BQA\). \(PC \parallel BQ\) 에서 \(\angle BQP = \angle CPQ = \angle MCP\).
  3. Step 3 — 따라서 \(\triangle MCP\) 는 이등변이고 \(MB = MP = MC\).
  4. Step 4 — 곧 \(M\) 이 \(BC\) 를 지름으로 하는 원 \(CPB\) 의 중심이므로, 반원에 대한 원주각은 직각이라는 정리로 \(\angle CPB = 90^\circ\) 를 얻는다.
  5. 다른 길 — \(\triangle MAB\) 와 \(\triangle PMC\) 에 사인법칙을 쓴다. \(\frac{BM}{\sin\angle MAB} = \frac{AB}{\sin\angle BMA} = \frac{PC}{\sin\angle PMC} = \frac{PM}{\sin\angle MCP}\) (가운데 등식은 \(AB=PC\) 와 \(\angle BMA + \angle PMC = 180^\circ\) 에서). \(\angle MAB = \angle MCP\) 이므로 \(BM = PM\).
이 문항이 가르치는 것
  • 등식은 선언이 아니라 근거와 함께 적는다. \(\angle QAB = \angle CPQ = \angle MCP\) 는 평행사변형과 이등변에서 나온다. 결론만 적으면 채점자는 그 사이를 채워 주지 않는다
  • 보조점 하나가 조건을 쓸 수 있게 만든다. 리포트는 이 문항에서 열 가지 넘는 보조점이 나왔다고 적었다
  • 사용된 정리는 이름을 밝힌다 — “angle in a semicircle” 처럼. 암묵적으로 쓰면 깎인다

문제

\(p\) 를 소수, \(n\) 을 \(n^6-1\) 이 \(p\) 로 나누어떨어지는 1보다 큰 가장 작은 양의 정수라 하자. \((n+1)^6-1\) 과 \((n+2)^6-1\) 중 적어도 하나가 \(p\) 로 나누어떨어짐을 증명하라.

학생 답안
“We begin by noting that \(n^6-1 = (n^3)^2-1\)
\(n^6-1 = (n^3-1)(n^3+1)\)
\(n^6-1 = (n-1)(n^2+n+1)(n+1)(n^2-n+1)\)
\(p\) does not divide \((n-1)^6-1 = (n-2)(n^2-n+1)(n)(n^2-3n+3)\)
\(p\) does not divide \((n-2)^6-1 = (n-3)(n^2-3n+3)(n-1)(n^2-5n+7)\)
In the first of these case we see that \(p\) divides \((n+1)^6-1 = n(n^2+3n+3)(n+2)(n^2+n+1)\)
in the second case \(p\) divides \((n+2)^6-1 = (n+1)(\cdots)(n+3)(n^2+3n+3)\)
We also note that \(4^6-1 = 4095 = 5\times819 = 5\times9\times91 = 13\times3\cdots\) \(4^6-1\) required”
부분 인수분해와 두 결론은 있으나, 둘을 잇는 핵심 한 문장과 \(n=2,3\) 예외 처리가 없다.
틀린 지점과 올바른 답

빠진 것 1 — 두 “does not divide” 줄과 결론 사이의 한 문장. 답안은 “\(p\) 가 \((n-1)^6-1\) 을 나누지 않는다” 를 적은 다음 바로 “In the first of these case…” 로 넘어간다. 그런데 these 가 무엇을 가리키는지가 아직 안 나왔다. 공식 해답에는 그 사이에 이 문장이 있다.

“These imply that, while \(p\) divides one of the four factors \((n-1)\), \((n^2+n+1)\), \((n+1)\), \((n^2-n+1)\) for any \(n\) where \(p \mid (n^6-1)\), for the least \(n>1\) we must have either \(p \mid (n^2+n+1)\) or \(p \mid (n+1)\).”

이 문장이 증명의 축이다. \(n\) 이 최소라는 조건이 네 인수를 둘로 좁히는 자리이고, 그래야 다음 두 줄의 “첫 번째 경우 / 두 번째 경우” 가 뜻을 갖는다.

빠진 것 2 — \(n>3\) 가정과 작은 \(n\) 예외. 위 논증은 \(n-2 > 1\) 이어야 하므로 \(n > 3\) 을 가정한 것이다. 답안에 이 가정이 적혀 있지 않고, \(n=2\) 와 \(n=3\) 을 따로 확인하지도 않았다. 공식 해답은 이렇게 마무리한다 — \(n=2\) 면 \(n^6-1 = 63 = 3^2 \times 7\) 이므로 \(p=3, 7\) 이고, \(3 \mid 4^6-1\), \(7 \mid 3^6-1\) 로 확인된다. \(n=3\) 이면 \(n^6-1 = 728 = 2^3 \times 7 \times 13\) 이므로 \(p=2, 13\) 이고, \(2 \mid 5^6-1\), \(13 \mid 4^6-1\) 로 확인된다.

답안 마지막 줄의 \(4095\) 소인수분해는 바로 이 \(n=3\) 예외 확인의 일부인데, 앞의 예외 처리가 없어 문장이 어디에 붙는지 알 수 없게 떠 있다.

인수분해 자체는 맞다. 네 줄 모두 정확하다.

공식 해답 (UKMT 채점자 리포트)
  1. \(n^6-1 = (n^3)^2-1 = (n^3-1)(n^3+1) = (n-1)(n^2+n+1)(n+1)(n^2-n+1)\).
  2. \(p \mid n^6-1\) 이므로 \(p\) 는 이 네 인수 가운데 하나를 나눈다.
  3. \(n\) 이 최소이므로, \(n>3\) 이면 \(p\) 는 \((n-1)^6-1 = (n-2)(n^2-n+1)n(n^2-3n+3)\) 도, \((n-2)^6-1 = (n-3)(n^2-3n+3)(n-1)(n^2-5n+7)\) 도 나누지 않는다.
  4. 이 둘에서 \(p \mid (n^2+n+1)\) 또는 \(p \mid (n+1)\) 로 좁혀진다.
  5. 첫째 경우: \(p \mid (n+1)^6-1 = n(n^2+3n+3)(n+2)(n^2+n+1)\). 둘째 경우: \(p \mid (n+2)^6-1 = (n+1)(n^2+5n+7)(n+3)(n^2+3n+3)\).
  6. 작은 \(n\) — \(n=2\): \(63 = 3^2\times7\) 이므로 \(p=3,7\). \(3 \mid 4^6-1\), \(7 \mid 3^6-1\). \(n=3\): \(728 = 2^3\times7\times13\) 이므로 \(p=2,13\). \(2 \mid 5^6-1\), \(4^6-1 = 4095 = 3^2\times5\times7\times13\) 이므로 \(13 \mid 4^6-1\).
  7. 합동식으로 쓰는 길 — 네 경우를 각각 본다. \(p \mid n^2+n+1\) 이면 \(n+1 \equiv -n^2\) 이므로 \((n+1)^6-1 \equiv n^{12}-1 = (n^6-1)(n^6+1) \equiv 0\). \(p \mid n+1\) 이면 \((n+2)^6-1 \equiv 1^6-1 = 0\). 나머지 두 경우는 최소성에 걸려 \(n=2\) 또는 \(n=3\) 으로 떨어진다.
이 문항이 가르치는 것
  • “최소” 라는 조건은 쓰는 자리가 정해져 있다 — 더 작은 \(n\) 에서 안 된다는 사실로 경우를 좁히는 데 쓴다. 이 문항에서는 네 인수를 둘로 줄인다
  • \(n^6-1\) 은 제곱의 차 → 세제곱의 합·차 순서로 네 인수까지 쪼개진다. 되풀이 쓰이는 꼴이다
  • \(n>3\) 을 가정하고 논증했으면 \(n=2, 3\) 을 반드시 따로 확인한다

문제

Björk 에게 \(1\times1\times1\) 각설탕 64개가 있다. 각 설탕은 white · demerara · muscovado 셋 중 하나의 맛이다. 이것을 \(4\times4\times4\) 정육면체로 쌓는다.

같은 맛의 각설탕 12개를 골라 서로소인 6쌍으로 묶되, 각 쌍의 두 설탕 중심 사이의 거리가 모두 같게 할 수 있음을 증명하라.

학생 답안
제출하지 않았다.
미응답 미제출. 학부모 전언 — “3번과 6번은 모르겠다고 합니다.”
틀린 지점과 올바른 답

채점자 리포트가 이 문항에 대해 남긴 말 (원문):

“Problem 6 proved hard enough to ensure that almost all candidates had something to think about throughout the exam.”

시험지 지시 3번: “One complete solution will gain more credit than several unfinished attempts. It is more important to complete a small number of questions than to try all the problems.”

공식 해답 (UKMT 채점자 리포트)
  1. \(4\times4\times4\) 정육면체를 서로 겹치지 않는 \(2\times2\times2\) 부분 정육면체 여덟 개로 나눈다.
  2. 각 부분 정육면체는 중심들이 한 변 \(\sqrt{2}\) 인 정사면체를 이루는 네 칸씩 두 묶음으로 갈라진다. 비둘기집 원리로 각 정사면체의 네 꼭짓점 가운데 두 칸은 같은 맛이다 — 정사면체 16개에서 거리 \(\sqrt{2}\) 인 같은 맛 쌍이 16쌍 나온다.
  3. 확장 비둘기집 원리로 세 맛 가운데 한 맛이 이 16쌍 중 여섯 쌍 이상을 차지한다 (\(16 \gt 5 \times 3\)). 부분 정육면체들이 서로 겹치지 않으므로 이 여섯 쌍은 서로소다.
이 문항이 가르치는 것
  • 여섯 문항 중 뒤로 갈수록 어렵다. 시험지 지시 4번 — “earlier questions tend to be easier … you are advised to concentrate on these problems first”
